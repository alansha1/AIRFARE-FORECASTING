# AIRFARE-FORECASTING
A Holistic Approach on Airfare Price Prediction Using Machine Learning Techniques. Predicts airline ticket prices using ML models (regression, trees, RF, GBM) on public datasets (flights, carriers, economics). Analyzes factors like stops, class, time; compares classical vs quantum ML. High accuracy (0.869); aids affordable booking. 



A machine learning pipeline that predicts airline ticket prices using classical and quantum ML techniques. Built on public datasets covering flights, carriers, and economic indicators.

What It Does
Predicts airfare prices with 86.9% accuracy
Compares multiple ML models: Linear Regression, Decision Trees, Random Forest, and Gradient Boosting
Analyses key pricing factors: number of stops, travel class, booking time, route, and carrier
Explores quantum ML as an alternative to classical approaches
